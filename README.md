# 个人记账管理系统

一个基于 Python Tkinter 的本地个人记账桌面应用，单文件运行，数据全部存在本地 JSON，无需联网、无需数据库。

- **当前版本**：v1.1.4
- **主程序**：`financialmanager.py`
- **数据存储**：本地 JSON（`records.json` / `goals.json` / `rules.json` / `categories.json` / `settings.json`），均在程序运行目录下
- **打包产物**：`dist/financialmanager.exe`（Windows 免安装版）

## 功能列表

### 记账与统计
- **收入/支出记录**：日期、类型、金额、用途备注，输入自动校验
- **智能自动分类**：根据用途关键词自动归入对应类别（交通 / 饮食 / 生活用品 / 学习 / 会员 / 话费 / 电费 等），支持用户自定义规则
- **月度目标**：为指定月份设置支出目标，实时显示剩余额度与达标/超支状态
- **月度统计**：按月查看总收入、总支出、结余与目标执行情况
- **消费分析图**：按类别统计的支出分布条形图，支持月份切换与鼠标滚轮缩放，可导出 PNG / PDF

### 跨月余额累计
- **余额自动结转**：上月结余（正数或负数）自动滚入下月，逐月累计
- **停记后重新累计开关**：界面左上角可勾选。勾选（默认）表示停记一段时间后重新开始记账时，旧账不再结转，从最新连续记账月算起；取消勾选则从最早记录一直累计
- 累计余额可在「本月摘要」中查看历史结转与累计结余

### 定投计划
- **自动计算定投金额**：每月建议定投额 =（上月结余中正数部分 + 本月收入）× 20%
- **左上角定投卡片**：主界面顶部醒目显示本月建议定投金额
- **定投计划窗口**：可查看各月定投建议与累计定投总额

### 其他
- **信念横幅**：主窗口顶部显示「我是有能力把握将来十倍甚至百倍资产增长的人。」
- **左侧操作栏可滚动**：内容较多时可上下滚动，操作按钮不会被截断

## 运行说明

### 方式一：直接运行 exe（Windows）
双击 `dist/financialmanager.exe` 即可。

### 方式二：从源码运行
```bash
pip install matplotlib
python financialmanager.py
```
> `tkinter` 为 Python 标准库，Windows 官方 Python 已内置。
